# 内容要点图：从内容关系到视觉模型

本指南配合 `排版规范.md` 使用。五张参考图保存在 `example_内容要点图/`；它们提供视觉组织范例，不作为书籍事实或用户评分的依据。借鉴信息结构，不照搬其字体、配色、阴影、渐变、纹理或底部总结。

## 从五张示例学到什么

| 参考 | 具体观察 | 可复用的方法 | 不应机械照搬 |
| --- | --- | --- | --- |
| 1.png：彼得·林奇 | 顶部原则小卡，中部大幅生命周期曲线与阶段分类对应，底部六类股票矩阵 | 让核心分析图成为正文的视觉中心；用位置对齐表达“阶段—类别”映射；用稳定的“特点/操作”字段比较类别 | 没有数据时不能画出貌似精确的收益曲线；不把所有书套成生命周期 |
| 2.png：认知驱动 | 左侧道/法/术导航与右侧内容块逐行对应，每条内容有语义图标 | 左侧少量分类锚点、右侧解释形成映射；图标与分隔线建立扫描节奏 | 列表前放箭头不等于流程；道法术只在笔记内容确实支持时使用 |
| 3.png：金钱心理学 | 核心主张条；理念分栏；方法采用图标—行动—解释三列；结论是短卡阵列 | 同一画面中按内容性质切换模型；字段对齐促进比较；行动句优先于长段落 | 不增加用户没有要求的底部总结，不把并列方法误画成严格执行顺序 |
| 4.png：影响力 | 外层积极/负面两章；积极部分再分理性/感性；行内图标区分说服、交换、联盟等 | 外层分章节，内层分概念；不同条目数可用图标列表表达；同层图标大小一致 | 不复制示例内容作为赫拉利等其他书的内容，也不默认示例的书籍归属正确 |
| 5.png：人生设计课 | 理念三栏、操作四栏，底部两模块并排；地图、笔记、路标等图标配合具体内容 | 按信息量安排整行或半行模块；有分类就分组，有路径就画路径；用图标区分概念与操作 | 不强迫每章三列，不因示例四列而把正文缩小，不复制底部口号 |

## 先写逻辑，再挑模型

每个一级模块先记录：**本章要回答的问题、核心判断、关系类型、模型、概念与连接、图标含义、资料依据**。这些信息随内容配置保存，不能只记录几个卡片标题。

| 内容关系 | 优先视觉模型 | 图形必须表达的东西 |
| --- | --- | --- |
| 并列/分类 | 图标卡、分类矩阵、共享字段的比较表 | 类别之间地位相当；排列顺序不暗示优劣 |
| 层级/包含 | 分支树、分组括号、父子节点 | 谁属于谁；最多外层章节与内层概念两层容器 |
| 顺序/过程 | 编号步骤、时间线、阶段带 | 阅读方向和前后关系；箭头旁必要时标注“随后/导致/转化” |
| 循环/反馈 | 闭合循环、明确的反馈回路 | 真正的回到起点或反馈边；不能用几组双向箭头冒充闭环 |
| 对照/权衡 | 左右对照、同字段矩阵、条件分支 | 对比对象和比较维度一致；“不等于”不代表“完全无关” |
| 映射 | 左右对应、阶段带与标签对齐、连接线图 | 一个概念具体对应什么；不要依靠模糊邻近位置让读者猜 |
| 多因素机制 | 有标注的关系图、输入—机制—结果图 | 作用方向、条件和边界；每根箭头有笔记或可靠资料支持 |
| 变化趋势 | 阶段曲线、前后对照或定量图表 | 无数值时标“示意”，只说明定性变化；有数据才提供数轴、单位、比例和来源 |

默认清单适用于独立建议、检查项、没有显式关系的短句。不要为追求视觉多样性捏造关系；也不要将有明确机制的内容降格为同尺寸列表。

## 画面结构与空间分配

- 固定结构：醒目主题 + 一句核心主张 + 2–4 个一级模块。核心主张应是可理解的判断，不仅是“本书三大要点”一类栏目说明。
- 先辨认最值得看懂的一条关系。有复杂且重要的机制时，为它分配较大的主分析区；其他模块负责补充。简单内容无需硬凑一张大图。
- 一级模块数量不是每章相同高度、相同列数的理由。保留统一外边距和间距，可采用整行分析图、较短图标列表、底部两块并列等有限组合。
- 章节重要性与信息量共同决定高度；优先保住正文32px和辅助26px。若三列放不下，改两列或行式布局；不要继续缩字。
- 允许轻量分隔线、留白和对齐直接分组，不必每个概念都加一层卡片。容器最多两层。
- 每个内层块一般包含“图标/模型节点 + 短标题 + 一两句解释”。共享类别字段保持同序，以便横向比较。
- 视线从主标题到核心主张，再到主要分析图与补充模块；连线不得跨过其他章节或穿过文字。背景、字体、圆角与图标风格始终一致。

## 图标作为语义，不是装饰

- 图标优先放在概念或动作旁，而不只放在章节标题角落。例如：实验用烧瓶、观察用放大镜、规则用文档、协作用人群或连接节点、风险用盾牌或警示符号。
- 相同概念复用同一图标；不同概念不要都用同一枚灯泡或星星。图标必须配文字，不能要求读者独自猜含义。
- 采用同一套可复用矢量图标或程序图形；单色/双色均来自主题色系，统一线宽、尺寸和视觉重量。语义线性图标通常约32–44px，概念主图标可适度放大。
- 纯序号帮助定位，不替代语义图标。只有确有识别价值的条目才加图标，不要求每条句子都配图。
- 不混用 emoji、写实图、厚重3D图标与细线图标；不从参考截图中裁取图标作为正式素材。
- 曲线、分支、阶段带、矩阵承担分析；图标承担识别。即使图标很多，缺少关系表达的卡片墙也不能算分析图。

## 真正可执行的确认稿

在用户已有的“内容要点图基本构架”确认项内，展示主题、核心主张以及每章的**关系和图形选择**，不另增加审批步骤。例如：

> 认知革命：共享故事如何促成合作；用“故事—共同认可—陌生人协作”机制图，故事/规则/人群图标辅助识别。农业革命：群体扩张与个体代价左右对照，比较人口、财富、生活三个方面。科学革命：只有笔记支持的资本—科学反馈用双向边；观察与实验不自动视作资本循环的一环。

确认过的核心判断不为迁就模型而改写；若绘图揭示逻辑缺失，简化模型或指出待核验关系。用户要求按新示例优化结构时，允许在已授权范围内重新组织呈现方式。

## 渲染与验收

- 用结构化内容和确定性排版制作标题、中文文字、图形、图标与图表；优先复用现有模板的视觉参数。
- 当前 `试排/人类简史/v1/scripts/render.py` 仅是有限模型试排器：它尚未实现真正闭环、层级树、映射图、定量图表或按内容分配模块高度。遇到这些模型必须补充渲染能力，不能把所有模型静默变成三张卡片，也不能声称指南已等同于组件代码。
- 几何检查覆盖文字/图形/图标/连线和模块边界；语义检查覆盖箭头、分组、比较维度、数据出处和作者观点/个人思考的区分。
- 看原图检查字形与细节，看360px宽缩略图检查扫描顺序。若只看标题和图形仍无法看出主要逻辑，先改模型或层级，而不是增加装饰。
- 没有为了图形丰富度增加不存在的数字、时间、排名或因果；没有用大幅空白、过密图标或多层容器掩盖薄弱内容。
