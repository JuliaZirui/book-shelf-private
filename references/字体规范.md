# 理性拆书局 · 字体规范

用户确认日期：2026-09-10。

## 指定字体

- 三类海报统一使用思源黑体（Adobe 版 CN），替代此前指定的“字由点字典黑”。
- 使用本目录下 `思源黑体(Adobe版-CN)/` 中的本地 TTF 文件，确保渲染可复现。
- 真实书籍封面中的文字保持原样，不受海报字体规范影响。

## 可用字重

| 字重 | 字体文件 |
| --- | --- |
| ExtraLight | `SourceHanSansCN-ExtraLight.ttf` |
| Light | `SourceHanSansCN-Light.ttf` |
| Normal | `SourceHanSansCN-Normal.ttf` |
| Regular | `SourceHanSansCN-Regular.ttf` |
| Medium | `SourceHanSansCN-Medium.ttf` |
| Bold | `SourceHanSansCN-Bold.ttf` |
| Heavy | `SourceHanSansCN-Heavy.ttf` |

各文字层级使用的字重、字号与行距，将在三类海报的排版规格中统一确定。
