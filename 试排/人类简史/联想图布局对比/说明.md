# 书籍联想图四方案试排

对应草图：A = IMG_4380.HEIC；B = IMG_4381.heic；C = IMG_4382.heic；D = IMG_4384.heic。

沿用已核验的五本书封面与分析方向。四版共用 1080 × 1440 画布、蓝色背景、思源黑体、居中标题、360px 宽主书封面；书名加粗。为了容纳四列布局，关联介绍统一精简为相同的两行短句。A、B 的书籍坐标相同，只改变连线；C 将主书移到上方，相关封面高240px，其余方案相关封面高220px。D 将关联书左右对称排列。封面保持正视原比例，无阴影、光晕。

草图未标示文字区，实际试排保留主书下方书名、作者及关联书下方介绍，因此连线按文字避让调整。箭头仅在C表达从主书延伸阅读的方向，不表示书籍间的因果或学术继承关系。
