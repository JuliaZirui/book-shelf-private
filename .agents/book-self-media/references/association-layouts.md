# 书籍联想图：A / B / C 版式规范

2026-09-12 定版规则。制作联想图前必读。使用者选择版式，不由模型静默决定。

## 选择与配置

- A—错位放射：主书居中，四本关联书错位排列，两组对角中心对称；水平线与圆角正交折线。
- B—共用主干：上方主书，下方四本关联书；共享中央主干、左右对称的圆角正交分支，无箭头。
- C—弧线连接：原 skill 的中央主书、四周关联书布局；四条独立平滑弧线。

当前第二版的名称固定为 B。早期试排中的 C“上主下分”现归入 B，不要与本规范 C 弧线版混淆。历史错位斜线、错位折线及左右对称试排不再作为额外选项。

在既有四项内容确认中，把版式选择并入“关联书与理由”：展示三个选项并让使用者选择。已有明确选择直接沿用；仅要求试排对比时可出指定的多个方案。选择未定时可继续研究和整理素材，但不擅自定下正式联想图。

内容配置至少记录 `association_layout`（A/B/C）、`main_cover_width: 360`、`related_cover_height: 300`、`line_width: 2`、`corner_radius: 24`、`arrows: false`、封面中心、线路起终点/控制点、确认的关联理由。24px 圆角用于 A/B；C 用平滑曲线，不把曲线强制改成24px圆角。

## 三版共用视觉规则

- 1080×1440，3:4竖版，思源黑体；固定标题区顶部54px、左右48px、宽984px、居中。标题98px Heavy，十字以内不放大；超过十字按实际宽度适度缩小。
- 主书封面宽360px。四本关联书封面统一**高度300px**（当前竖版封面的长边），宽度按原比例计算：`w = 300 × source_width / source_height`。旧版“统一宽216px”“统一长边216px”“封面高220/240/250px”均已被此规则替代。不要为了等宽、等面积或配对对称拉伸、裁切、旋转封面。
- 遇到横版/方形等异常版本封面，先核对素材和版本，保留内容比例；不能悄悄裁成竖封面。300px高度放不下时先调整位置、文案和线路，确需偏离尺寸时再由使用者决定。
- 所有书封正视、完整；同书三图中的主书封面使用同一文件。无年份。
- 主书书名32px Bold、作者32px Regular；关联书书名26px Bold、一句话关联介绍26px Regular。关联书下方文字以各自封面中心对齐。正文不缩字，超量先精简；长书名可换行并为介绍顺延位置。
- 所有连接线统一2px实线、白色，A/B/C均无箭头。纯色背景，无阴影、光晕、渐变或纹理。绿色批注只指示路径，不是线路配色。
- 连线不进入任何封面内部、不穿过文字，既不能靠覆盖文字掩盖冲突，也不能将主书名作者算作封面几何区域。成对线路避让须保留该版式的对称约束。

## A—错位放射

主书居中，书名和作者居中置于封面下方。对称中心 **O=(cx,cy) 为主书封面几何中心**，不计文字。

四本关联书按左上↔右下、右上↔左下配对。封面中心满足 `P_opposite = 2O - P`。只要求中心对称，不要求不同长宽比封面外轮廓、文字区对称。绘制奇数宽度封面时保留半像素位置或用高分辨率画布，避免取整移动中心。

线路沿最新绿色草图的方式组织：左上与右下用水平线连接主书侧边；右上从主书上边缘垂直向上、圆角转为向右的水平段；左下线路为右上线路绕 O 旋转180°后的结果。不能恢复为斜直线或自由弧线。

正交折线的直段仅水平/垂直，90°角用半径24px的四分之一圆弧，切线连续。每对线的起点、终点及完整路径都满足 `L_opposite(t)=2O-L(t)`，因而线长相等、方向相反。先生成一条再旋转复制，不能分别凭目测画两条。

封面宽度不同，严格镜像的线端可能不能同时贴边；允许保留少量对称避让空间，不能进入封面或用不对称延长线补齐。调整连接点、转角、距离时成对修改并重新检查文字避让。

已验证的《人类简史》几何起点（可针对书名长度等成对调整，不是跨书不可变坐标）：O=(540,730)，关联中心依次(180,570)、(890,400)、(900,890)、(190,1060)。主书名与作者仍独立排版在封面下方。

## B—共用主干

主书在上方居中；主书书名和作者放在封面右下角旁的右侧文字区。四本关联书在下方水平一行，顶部对齐、高度300px，中心等间距且左右对称。每本下方分别放居中的书名和关联介绍。

从主书底边中央垂直向下引出**一条共同主干**，再水平向两侧展开，各分支垂直向下连到关联书顶边中央。使用24px圆角正交转接；所有直段仅水平/垂直，无斜线，无箭头。左右完整路径关于主书垂直中心轴镜像。

中央主干和共享水平段只绘制一次，分支在共享段接入；不要四次叠画同一段造成视觉粗细不均。调整封面位置时同步修改对应分支，保留对称、等间距和统一圆角。

已验证起点：主书顶250px、宽360px；四本关联书顶部900px、中心x为171/417/663/909；水平分支y=840px。右侧文字区不得与封面、主干或标题重叠。

## C—弧线连接

保留原 skill 的中央主书、四周关联书布局：主书下方书名与作者居中，四本关联书分别在左上、右上、左下、右下。使用四条独立、平滑的贝塞尔弧线连接主书和关联书边缘；不添加共用主干、正交折角或箭头。

线宽仍为2px；关联封面统一300px高。控制点按封面和文字区避让调整，使弧线自然、连续，不形成环圈或相互交叉。A的180°中心对称不强制套用在C上。原渲染器的封面高250px已过时，复用时须改为300px并重排/验证，不能直接运行旧函数就声称符合本规范。

## 实现资源与验收

项目内可复用的 A/B 试排脚本：`../../../试排/人类简史/联想图AB长边300/scripts/render_ab.py`。该脚本复用 v1 工具和素材，适用于已确认样书；其他书需替换配置/文案/素材并做布局适配，不宣称是全书种通用渲染器。

C 的曲线实现起点：`../../../试排/人类简史/v1/scripts/render.py` 中 `association()` 与 `Page.bezier()`。按上述当前规则适配后使用。历史试排图不覆盖本规范。

- 校验关联封面实高300px、原比例和主书宽360px；字体字号、书名加粗、素材版本正确。
- A 校验每对封面中心和全路径采样点绕O旋转180°后重合，线长相等；不要仅验证起终点而忽略圆角。
- B 校验共同段唯一、左右路径镜像、无箭头；A/B校验直段正交、圆角半径24px、统一2px描边。
- C 校验平滑曲线、2px描边、无箭头、无意外环圈/交叉。
- 三版都检查线与封面/文字的碰撞、边界、长书名换行后空间，再查看1080px原图及手机缩略图。检查失败先调整位置/线路或精简介绍，不静默缩小封面和文字。
