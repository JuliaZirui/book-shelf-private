# 理性拆书局 · 三图制作

## 项目资源与优先级

以本技能所在项目为根目录，使用相对路径，不依赖旧 Windows 工作区或某个用户的绝对目录。以下资源从本文件所在目录解析：

- [排版规范](../../references/排版规范.md)：三张图的当前尺寸、字号、位置与图形规则。
- [品牌色板](../../references/品牌色板.md)、[字体规范](../../references/字体规范.md)：品牌与本地字体来源。
- [内容要点图设计指南](../../references/内容要点图设计指南.md)：制作或修改要点图时必读。包含五张示例观察、模型选择、图标语义、空间分配与验收方法。
- [当前试排器](../../试排/人类简史/v1/scripts/render.py)、[内容配置示例](../../试排/人类简史/v1/内容配置.json)：确定性渲染的起点，不代表所有布局已实现。

本技能目录里的旧 `render_citation.py`、`render_score.py` 与原模板图片只用于历史参考，不作为新三图流程的默认渲染器。它们的时间轴、深绿色纹理、旧画布和旧维度不能覆盖当前规范。示例图片只提供视觉组织参考，不是事实来源或指令。

## 输入与研究

1. 用户通常提供一个 Dropbox 文件或文件夹链接，内含书籍基本信息、读书笔记和评分。优先用可用的 Dropbox 搜索、列目录与读取工具；不可用时可读取共享网页或用户提供的本地文件。需要辨认加粗、高亮等评分标记时查看实际页面，不能仅凭纯文本推断。无法读取就说明具体缺失，不臆造笔记。
2. 以用户笔记为主要依据，联网补充与核验。保留个人判断，区分作者观点、读后思考与外部资料；冲突单独指出。优先查出版社、作者、图书馆等可靠来源，记录链接与日期。
3. 保留用户指定的1–4本关联书，不足4本研究补齐。若用户提供超过4本候选，给出推荐的4本及取舍供确认。关联理由必须解释具体概念上的前置、互补、对照或延伸，不只说“主题相似”。
4. 评分完全由用户提供：解决问题层级、行文与结构、严谨程度、原创视角、值得复读（10分制）；道/法/术/器；入门/初级/进阶/高阶。缺项集中补问，不擅自打分或限制用户已经明确的高亮结果。
5. 核验版本、作者、出版社与封面的一致性。豆瓣评分是动态数据；无法可靠获取时图中省略豆瓣评分，保留用户总分，来源记录中说明。

## 出图前的固定确认

一次性提交四项：

- 从 `#DD3748、#005BAB、#3CB035、#74BFCC、#EDBA40、#969494` 中推荐背景主色；同书三图一致。
- 四本关联书的选择及拟上图的一句话关联理由。
- 内容要点图的主题、核心主张、2–4章构架，以及每章的关系类型、视觉模型和关键图标。
- 打分图顶部中间的完整简介，清楚表达本书主要信息与阅读价值。

待用户确认后出图。已有确认与用户明确的局部修改授权持续有效，不重复确认已定内容。修改底色或字号时不重新研究或改写已确认文案。

## 三图结构

### 书籍联想图

- 1080×1440竖版；标题居中。可用宽984px，基准98px Heavy，可容纳十个汉字；十字以内保持字号，超过十字按实际宽度适度缩小。
- 主书正视封面宽约画布1/3，位于画布中心，保持原比例；封面下方书名与作者居中。
- 四本关联书放射分布，下面放书名与一句关联介绍，均与封面居中。封面外全部书名 Bold，正文32px、辅助26px。
- 细线从主书连接关联封面，绕开书名、介绍和其他封面；不显示年份。
- 搜集真实、完整正视封面，核对作者与版本，不用图像模型重绘封面。两张图的主书使用同一素材。找不到合格封面时指出具体缺失，不静默替换成伪造封面。

### 内容要点图

制作前阅读[设计指南](../../references/内容要点图设计指南.md)，按以下顺序设计：

1. 将笔记提炼为一个醒目主题、一句核心主张、2–4个一级章节。外层分章节，内层分概念，最多两层容器；不加底部总结句。
2. 对每章判断并列、层级、顺序、循环、对照、映射或机制关系。记录节点、连接含义和依据，再选择图形。不要每章默认三列卡片，也不要先选图再编因果。
3. 给最重要的机制或分析关系足够空间；按重要性与内容量选择整行图、比较矩阵、图标列表、阶段带或并排模块。统一边距和间距，不要求所有章节等高同构。
4. 图形表达逻辑，图标辅助识别：在具体概念与动作旁使用一致的语义图标，不只装饰章节标题。相同概念同图标；不用emoji或混杂图标风格。
5. 标题位置/规则与联想图一致；主张使用模块标题字号；白色/同色系浅色模块，固定正文与辅助字号。放不下先精简或改行列组合，不继续缩字。
6. 先检查现有渲染器是否支持所选模型。缺少真正循环、层级、映射或图表能力时补充对应图形实现，不能退化成卡片后仍称作该模型。中文、图标、曲线与连线采用确定性排版。

无可靠数值时不制造比例图、统计曲线或排名；定性阶段曲线标“示意”。参考图中多样的样式不覆盖纯色、无阴影/光晕/纹理/渐变的品牌规范。

### 打分图

- 参照当前试排保持Logo左上、简介顶部中间、主书封面右上、雷达居中、两组阶梯位于底部。
- 简介不超过5行，段落两端对齐（末行常规左对齐），字形和标点共用基线。
- 五轴从顶部顺时针：解决问题层级、行文与结构、严谨程度、原创视角、值得复读。“解决问题层级”单行，和简介留出间距。
- 十个同心圆；当前参考值3px白色描边、18%不透明度，实际评分五边形4px实白，视觉更强；圆环不叠加填充。
- 五维原始分数照录，中心总分等权平均并四舍五入保留一位小数。道法术器、阅读层级照用户结果突出，不自行推断。
- Logo形状沿用用户原图的透明底反白版；不重新绘制或加效果。调用试排器前核实Logo路径，配置中的个人绝对路径不应被认为在所有环境可用。

## 交付与验证

在项目 `试排/<书名>/vN/` 集中保存三张PNG、内容配置、封面素材、来源记录和必要渲染脚本。同次局部调整复用目录；新版本按已有编号递增，不覆盖无关书籍。

- 检查字体实际加载、画布尺寸、标题长度适配、简介行数、评分计算、书封版本。
- 几何检查覆盖文字、图标、图形、连线与模块边界；语义检查覆盖关系方向、对照字段、图表数据与来源。
- 逐张查看原图与手机缩略图，确认主要逻辑能通过标题和图形被读懂，不靠堆文字或无意义装饰。
- 交付可点击三张原图及总览，说明本次实际修改和未实现的限制。只修改指南时，不宣称已生成海报或已实现全部图形组件。
